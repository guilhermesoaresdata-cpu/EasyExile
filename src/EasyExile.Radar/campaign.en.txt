# EasyExile campaign guide.
#
# A linear list of typed ACTIONS, not a list of zones. That distinction is the
# whole file: several things happen inside one zone, and the zone listed after
# this one is often not reachable through a door from it — The Bone Pits is a
# pocket off Mastodon Badlands and you leave it by waypoint. A guide that only
# knows zones stands in the pocket waiting for a door.
#
# The shape is exile-leveling's (MIT, github.com/HeartofPhos/exile-leveling),
# which is the model every good levelling tool converged on.
#
# Keyed by the client's INTERNAL area code, never by the displayed name: the
# code is the same in every language, and this client is not in English.
#
#   act <n> <name>
#   zone  <code> <name>        a zone on the main line
#   zone? <code> <name>        an optional zone
#   enter <code> <name>        walk to the door leading there
#   waypoint                   take the waypoint or portal out
#   kill  <name>               kill something in this zone
#   take  <name>               pick something up in this zone
#   talk  <name>               speak to someone in this zone
#   note  <text>               anything else
#   a trailing ? on a verb marks the step optional; " | " starts a hint
#
# Area codes from path-of-levelling-2 (MIT) cross-checked against codes this
# tool learned from the running client. Step content derived from the community
# walkthrough collected in github.com/nicolasbagatello/poe2-helper.
